# 网页归档交换范围

## 合成 WARC 发生器

`python3 -m lab.archives <目录>` 产生本地合成 WARC，`python3 -m lab.warc_demo` 演示完整接收流程。限定 WARC/1.1、CRLF 头、十进制 Content-Length 和 sha256 十六进制摘要。response 块含 HTTP 响应头及按 HTTP Content-Length 表示的实体；不使用 chunked、HTTP 内容编码或网络回访。revisit 使用 identical-payload-digest 配置并以 WARC-Refers-To 指向捕获 ID，正文沿引用链解析；metadata 只作为关联字段记录。WARC-Block-Digest 对整个 WARC 内容块计算，WARC-Payload-Digest 对 response 的 HTTP 实体计算，HTTP 头不计入正文。目标 URI 为合成域名，无需请求，归档正文只作字节保存，不执行页面也不访问网址。

## 样本含义

- `forward.warc`：前向重访引用，revisit 出现在被引用 response 之前，同包内含 metadata。
- `first.warc` / `later.warc`：跨包关系的原文与重访两半。
- `earlier.warc` / `later-ref.warc`：跨包引用，later 包的 revisit 指向 earlier 包已收录的捕获。
- `cycle.warc`：两个 revisit 互相引用，展示不可闭合引用成环。
- `truncated.warc`：缺少尾部字节，前面已暂存记录保留，整包判失败且不可挂载。
- `repeated.warc`：同一 record-id 同内容重复，对象复用、访问证据各自保留。
- `conflict.warc`：同一 record-id 换了正文，必须报冲突，不能按 URL 合并访问。
- `joined.warc.gz`：按记录切开的拼接 gzip（两个 gzip 成员），每个成员解压后仍按 WARC 字节长度分帧。

## 接收与封存语义（sealvault.webarchive）

解析器 `sealvault/webarchive/warc.py` 支持未压缩与单成员/拼接 gzip，按 WARC Content-Length 读取原始块；默认解压总量 64 MiB、单记录 16 MiB，可在调用时下调。块摘要（整个 WARC 块）与正文摘要（HTTP 实体）分别校验。记录级语义错误（摘要不符、类型/配置不支持）进入记录原因；分帧、截断、超限为致命错误，已解析记录仍然暂存，但整包不会成功。

入库器 `sealvault/webarchive/ingest.py` 为每次捕获（response/revisit）保存记录身份、目标网址、WARC 时间、HTTP 状态、块对象与正文对象的关联。revisit 可以先于被引用记录、可以指向同库已收录捕获；解析结束仍找不到依赖、引用成环或摘要不一致时，捕获保留 `unresolved`、`cycle`、`digest_mismatch` 等待处理原因，整包进入 `review` 且禁止挂载。重复 record-id 同内容复用对象，换内容标记 `conflict`；绝不按 URL 合并不同访问。

挂载前 `warc.get` 展示捕获清单与未解决引用；只有这一组全部核验通过且案件版本仍有效（draft、revision 匹配），`warc.mount` 才能整体挂载为案件附件。正文与 WARC 块按内容去重存入对象库，每次访问的捕获证据独立保留。重启后重开同一数据库即可继续处理，`warc.describe_capture` 说明对象、捕获与案件附件之间的关系。

## 命令

- `warc-ingest <ingest_id> <source> <actor> [--max-total N] [--max-record N]`：接收本地 WARC。
- `warc-resolve <ingest_id> <actor>`：解析 revisit 引用链并标记待处理原因。
- `warc-get <ingest_id>`：展示捕获清单、未解决引用与案件附件。
- `warc-mount <ingest_id> <case_id> <expected_revision> <actor>`：整包挂载到案件。
- `warc-describe <record_id>`：说明某条捕获的对象、引用与附件关系。

JSON 操作对应 `warc.ingest`、`warc.ingest_base64`、`warc.resolve`、`warc.mount`、`warc.get`、`warc.list`、`warc.abandon`、`warc.describe_capture`。
