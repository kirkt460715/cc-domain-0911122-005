# 网页归档交换范围
python3 -m lab.archives /tmp/archives 产生本地合成 WARC。限定 WARC/1.1、CRLF 头、十进制 Content-Length 和 sha256 十六进制摘要。response 块含 HTTP 响应头及按 Content-Length 表示的实体；不使用 chunked、HTTP 内容编码或网络回访。revisit 使用 identical-payload-digest 配置并以 WARC-Refers-To 指向捕获 ID，正文沿引用链解析；metadata 只作为关联字段记录。WARC-Block-Digest 对整个 WARC 内容块计算，WARC-Payload-Digest 对 response 的 HTTP 实体计算。目标 URI 为合成域名，无需请求。
forward 是前向重访引用，first/later 展示跨包关系，cycle 展示不可闭合引用，truncated 缺少尾部字节，repeated 重复原记录，joined 是按记录切开的拼接 gzip。每个成员解压后仍按 WARC 字节长度分帧。默认建议总量 64 MiB、单记录 16 MiB，运行配置可降低限额。生成器只表达归档格式，不把捕获写入证据库。
